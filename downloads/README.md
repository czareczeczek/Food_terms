# Gotowy pakiet Google

Plik `straznik-swiezosci-google-drive.zip` zawiera zbudowaną aplikację, serwer Google Apps Script, manifest i instrukcję publikacji. Jest kopią pakietu wygenerowanego ze źródeł tej aplikacji poleceniem `npm run build:google`.

Na stronie tego pliku w GitHub użyj przycisku pobrania surowego pliku (**Download raw file**). Rozpakuj ZIP i wykonaj `INSTRUKCJA.txt`. Nie potrzebujesz Node.js do użycia gotowego pakietu.

Całe źródła możesz pobrać z widoku tej gałęzi przez **Code → Download ZIP**. Publikacja w Google i zgoda konta pozostają osobnymi krokami.
